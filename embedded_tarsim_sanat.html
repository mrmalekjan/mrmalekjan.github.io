Overview

  • Operating System: FreeRTOS

  • Version Control: Git
  • Peripherals: UART, SPI, GPIO, TIMER, EXTI, I2C, CAN, ADC, DAC, USART

Projects History

1. SiVo — Elevator Speaker System

Elevator speaker system that plays music, announces floors, and connects directly to the elevator phone. Embedded Systems: WCH/ST microcontrollers and Raspberry ICs. Peripherals: UART, SPI, GPIO, TIMER, EXTI. OS: FreeRTOS.

2. SiAx — Elevator Access Control (RFID)

Elevator access control system using RFID technology and announcing floors and authorized people, with direct connection to the Sidex system. Embedded Systems: WCH/ST microcontrollers and Raspberry ICs. Peripherals: UART, GPIO, TIMER, EXTI, I2C, SPI. OS: FreeRTOS.

3. Sidex Firmware

Main part of the access control system, consisting of GSM communication, SD card, OLED display, speaker, rotary switch and push buttons, Ethernet connections, different power-up modes (plug and battery operated), and five powerful microcontrollers working in coordination. Peripherals: USART, UART, GPIO, TIMER, EXTI, I2C, SPI, CAN, ADC, DAC. OS: FreeRTOS.

4. Sidex Web API

IoT device API built with the .NET framework that connects Sidex to a server and saves all Sidex data in an SQL Server database.

5. Destination Control System Simulator

A graphical interface built using React that verifies Sidex performance, checks sample data logs, and generates random data for training destination system AI algorithms.

6. SiTel Echo+ — Touch-Screen Telephone

A touch-screen telephone that connects to the telephone network and communicates directly with the SiAx system. Embedded Systems: WCH/ST microcontrollers. Peripherals: UART, GPIO, TIMER, EXTI, I2C, ADC. OS: FreeRTOS.

7. SiHall — Elevator Panel Integration

System connecting the elevator panel to the Sidex system via stable and secure CAN or ModBus communication. Embedded Systems: WCH/ST microcontrollers. Peripherals: CAN, UART, GPIO, TIMER, EXTI, I2C, DAC. OS: FreeRTOS.
